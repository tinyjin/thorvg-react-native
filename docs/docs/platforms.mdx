## Android

Canvases render into a `TextureView` by default. `androidBackingView="SurfaceView"` draws into a `SurfaceView` instead.

Android supports `'gl'` (OpenGL ES, the default) and `'sw'`. Other renderers fall back to `'sw'`.

## iOS

Run `pod install` in your `ios` directory after installing the package.

iOS supports `'sw'` (the default) and `'wg'` (WebGPU on Metal, experimental). Other renderers fall back to `'sw'`.

### WebGPU Support

`'wg'` is experimental and not included in the published package. Build it from the repository:

```sh
git clone --recursive https://github.com/tinyjin/thorvg-react-native.git
cd thorvg-react-native && yarn
yarn build:thorvg
yarn package:binaries webgpu
```

Install it in your app, run `pod install`, and select the renderer with `useThorVG({ renderer: 'wg' })`:

```sh
npm install /path/to/thorvg-react-native/build/binaries/thorvg-react-native-webgpu
```

It adds about 5.5 MB to the app binary. Without it, `'wg'` falls back to `'sw'`.

## Web

On web the package runs `@thorvg/webcanvas`, which loads `thorvg.wasm` from unpkg by default. To serve it yourself, copy it into your static folder:

```sh
npx setup-thorvg-web public
```

and pass `locateFile`:

```ts
useThorVG({ locateFile: (path) => '/' + path.split('/').pop() });
```

### Threads

`threads` runs the engine with worker threads on every platform. It defaults to `0`.

```ts
useThorVG({ threads: 4 });
```

On web it loads the threaded WebCanvas build, which needs a [cross-origin isolated](https://developer.mozilla.org/en-US/docs/Web/API/Window/crossOriginIsolated) page. Serve your page with:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

Without these headers, ThorVG runs without worker threads and logs a warning in development.

The threaded build is imported at runtime from unpkg, so a Content Security Policy must allow `'unsafe-eval'` and the script origin. To serve it yourself, `npx setup-thorvg-web public` also copies it into `public/thread`:

```ts
useThorVG({ threads: 4, locateFile: (path) => '/thread/' + path.split('/').pop() });
```

## Differences from WebCanvas

| Feature | Android and iOS | Web |
| --- | --- | --- |
| `TVG.Video` | Not available | Not exposed by this package |
| `Font.load(name)` with the default provider | Needs `Font.provider()` | Fontsource |
| Lottie audio playback | Events through `resolver()` only | Built in |
| `locateFile` | Ignored | Supported |
