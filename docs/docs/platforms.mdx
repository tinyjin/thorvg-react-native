## Android

Canvases render into a `TextureView` by default. `androidBackingView="SurfaceView"` draws into a `SurfaceView` instead.

Android supports `'gl'` (OpenGL ES, the default), `'vk'` (Vulkan, experimental) and `'sw'`. Other renderers fall back to `'sw'`.

`'vk'` is built for the 64-bit ABIs (`arm64-v8a` and `x86_64`). On 32-bit ABIs, and on devices without a usable Vulkan driver, it falls back to `'sw'`.

## iOS

Run `pod install` in your `ios` directory after installing the package.

iOS supports `'sw'` (the default) and `'mtl'` (Metal, experimental). Other renderers fall back to `'sw'`.

`'mtl'` draws into the view's `CAMetalLayer`.

## GPU Engines

`'mtl'` and `'vk'` come from experimental ThorVG backends that are not part of a ThorVG release yet. The `gpu` branch builds them into the engine:

```sh
git clone --recursive -b gpu https://github.com/tinyjin/thorvg-react-native.git
cd thorvg-react-native && yarn
yarn build:thorvg
yarn pack
```

Install the packed archive in your app and run `pod install`. Select a renderer with `useThorVG({ renderer: 'mtl' })` on iOS or `useThorVG({ renderer: 'vk' })` on Android.

`yarn build:thorvg` starts from the ThorVG release in the `thorvg` submodule and cherry-picks the backend commits pinned in `native/thorvg-gpu.txt`:

| Line | Meaning |
| --- | --- |
| `metal https://github.com/tinyjin/thorvg.git jinny/metal-engine <commit>` | Metal backend, built for iOS |
| `vulkan https://github.com/tinyjin/thorvg.git jinny/vulkan-engine <commit>` | Vulkan backend, built for Android |

To update a backend, change its commit and run `yarn build:thorvg` again. Both backends edit the same build options and engine registration, and `native/thorvg-rerere` records how those edits are combined, so known conflicts resolve without help. A conflict it has not seen stops the build. Resolve it in `build/thorvg/source`, run `git add` and `git cherry-pick --continue` there, run `yarn build:thorvg` again, and commit the new files in `native/thorvg-rerere`.

| Platform | Engines in the build |
| --- | --- |
| iOS | `sw`, `mtl` |
| Android `arm64-v8a`, `x86_64` | `sw`, `gl`, `vk` |
| Android `armeabi-v7a`, `x86` | `sw`, `gl` |

## WebGPU Support

`'wg'` is experimental and not included in the published package. Build it from the repository:

```sh
git clone --recursive https://github.com/tinyjin/thorvg-react-native.git
cd thorvg-react-native && yarn
yarn build:thorvg
yarn package:binaries webgpu
```

Install it in your app, run `pod install`, and select the renderer with `useThorVG({ renderer: 'wg' })`:

```sh
npm install /path/to/thorvg-react-native/build/binaries/thorvg-react-native-webgpu
```

It adds about 5.5 MB to the app binary. Without it, `'wg'` falls back to `'sw'`.

## Web

On web the package runs `@thorvg/webcanvas`, which loads `thorvg.wasm` from unpkg by default. To serve it yourself, copy it into your static folder:

```sh
npx setup-thorvg-web public
```

and pass `locateFile`:

```ts
useThorVG({ locateFile: (path) => '/' + path.split('/').pop() });
```

### Threads

`threads` runs the engine with worker threads on every platform. It defaults to `0`.

```ts
useThorVG({ threads: 4 });
```

On web it loads the threaded WebCanvas build, which needs a [cross-origin isolated](https://developer.mozilla.org/en-US/docs/Web/API/Window/crossOriginIsolated) page. Serve your page with:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

Without these headers, ThorVG runs without worker threads and logs a warning in development.

The threaded build is imported at runtime from unpkg, so a Content Security Policy must allow `'unsafe-eval'` and the script origin. To serve it yourself, `npx setup-thorvg-web public` also copies it into `public/thread`:

```ts
useThorVG({ threads: 4, locateFile: (path) => '/thread/' + path.split('/').pop() });
```

## Differences from WebCanvas

| Feature | Android and iOS | Web |
| --- | --- | --- |
| `TVG.Video` | Not available | Not exposed by this package |
| `Font.load(name)` with the default provider | Needs `Font.provider()` | Fontsource |
| Lottie audio playback | Events through `resolver()` only | Built in |
| `locateFile` | Ignored | Supported |
