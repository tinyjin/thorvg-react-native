`thorvg-react-native` brings [ThorVG](https://github.com/thorvg/thorvg) vector graphics and Lottie to React Native on Android, iOS and web.

Draw with React components, or with the [`@thorvg/webcanvas`](https://www.npmjs.com/package/@thorvg/webcanvas) API. The same code draws the same result on every platform.

## Requirements

- React Native with the New Architecture
- iOS 15.1+
- Android API 24+

## Installation

```sh
npm install thorvg-react-native
cd ios && pod install
```

With Expo:

```sh
npx expo install thorvg-react-native
npx expo prebuild
```

## Your first canvas

```tsx
import { Canvas, Rect } from 'thorvg-react-native';

const Example = () => (
  <Canvas width={200} height={160}>
    <Rect
      x={20}
      y={20}
      width={160}
      height={120}
      rx={16}
      ry={16}
      fill="#2563eb"
    />
  </Canvas>
);

export default Example;
```

The [components](./components/overview) draw without any setup. `Canvas` initializes ThorVG and draws its children in order.

The same drawing with the [WebCanvas API](./guides/canvas):

```tsx
import { useEffect, useRef } from 'react';
import { Canvas, useThorVG } from 'thorvg-react-native';

const Example = () => {
  const TVG = useThorVG();
  const view = useRef<Canvas>(null);

  useEffect(() => {
    if (!TVG) return;
    const canvas = new TVG.Canvas(view, { width: 200, height: 160 });

    const shape = new TVG.Shape();
    shape
      .appendRect(20, 20, 160, 120, { rx: 16, ry: 16 })
      .fill(37, 99, 235, 255);
    canvas.add(shape).render();

    return () => canvas.destroy();
  }, [TVG]);

  return <Canvas ref={view} />;
};
```

`useThorVG()` returns `null` until ThorVG is ready and then the ThorVG namespace (`TVG`). `new TVG.Canvas(view, options)` creates a WebCanvas `Canvas` on the view, with the same methods such as `add`, `update` and `render`. Both can be combined through [refs](./components/overview#refs).
